
# CampusNotes

CampusNotes is a simple note management website designed for college students.

## Features
- Add new notes
- View saved notes
- Delete notes
- Save notes using browser Local Storage

## Technologies Used
- HTML5
- CSS3
- JavaScript

## How to Run
1. Download or clone the repository.
2. Open the project folder.
3. Open index.html in a web browser.

## Purpose
The project helps students manage their study notes in one place.
